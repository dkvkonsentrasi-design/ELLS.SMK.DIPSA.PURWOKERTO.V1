Bagian 4

🐍 Matplotlib

Matplotlib adalah library Python yang dapat digunakan untuk membuat berbagai jenis grafik.

Mengimpor Matplotlib

import matplotlib.pyplot as plt

Alias plt adalah nama singkat yang umum digunakan untuk modul pyplot.

Perintah dasar yang sering digunakan

PerintahFungsi
plt.bar()Membuat grafik batang.
plt.plot()Membuat grafik garis.
plt.scatter()Membuat scatter plot.
plt.title()Memberi judul grafik.
plt.xlabel()Memberi nama sumbu X.
plt.ylabel()Memberi nama sumbu Y.
plt.legend()Menampilkan keterangan/legend.
plt.grid()Menampilkan garis bantu.
plt.show()Menampilkan grafik.

Bagian 6

📊 Grafik Batang

Grafik batang cocok untuk membandingkan nilai antar-kategori.

Contoh sederhana

import matplotlib.pyplot as plt

mata_pelajaran = ["Matematika", "Bahasa", "Informatika"]
nilai = [82, 78, 90]

plt.bar(mata_pelajaran, nilai)
plt.title("Nilai Rata-rata Mata Pelajaran")
plt.xlabel("Mata Pelajaran")
plt.ylabel("Nilai")
plt.show()

Bagaimana membaca grafik?

Batang yang lebih tinggi menunjukkan nilai yang lebih besar. Dari contoh tersebut, Informatika memiliki nilai 90 sehingga batangnya paling tinggi.

Kapan digunakan? Gunakan grafik batang ketika ingin membandingkan beberapa kategori, misalnya nilai antar-mata pelajaran, jumlah produk terjual, atau jumlah siswa tiap kelas.
Bagian 7

📈 Grafik Garis

Grafik garis cocok untuk melihat perubahan atau perkembangan data berdasarkan urutan tertentu, misalnya waktu.

Contoh dasar

import matplotlib.pyplot as plt

bulan = ["Januari", "Februari", "Maret", "April", "Mei", "Juni"]
penjualan = [20, 25, 23, 30, 35, 32]

plt.plot(bulan, penjualan, marker="o")
plt.title("Perkembangan Penjualan")
plt.xlabel("Bulan")
plt.ylabel("Jumlah Penjualan")
plt.show()

Memahami marker="o"

Parameter tersebut menambahkan titik pada setiap data sehingga posisi nilai lebih mudah terlihat.

Menambahkan grid

plt.plot(bulan, penjualan, marker="o")
plt.title("Perkembangan Penjualan")
plt.xlabel("Bulan")
plt.ylabel("Jumlah Penjualan")
plt.grid()
plt.show()
Ingat: Grafik garis sangat berguna untuk melihat kecenderungan data dari satu waktu ke waktu berikutnya.
Bagian 8

🔵 Scatter Plot

Scatter plot menampilkan data sebagai titik-titik. Grafik ini cocok untuk melihat hubungan antara dua variabel.

Contoh

import matplotlib.pyplot as plt

jam_belajar = [1, 2, 3, 4, 5, 6]
nilai = [60, 65, 70, 76, 82, 88]

plt.scatter(jam_belajar, nilai)
plt.title("Hubungan Jam Belajar dan Nilai")
plt.xlabel("Jam Belajar")
plt.ylabel("Nilai")
plt.show()

Pada contoh tersebut, sumbu X berisi jam belajar dan sumbu Y berisi nilai. Titik-titik membantu kita melihat pola hubungan kedua data.

Catatan penting: Scatter plot dapat menunjukkan pola hubungan pada data, tetapi sebuah grafik saja tidak membuktikan bahwa satu variabel pasti menyebabkan variabel lainnya.
Bagian 9

🏷️ Membuat Grafik Lebih Mudah Dipahami

Grafik sebaiknya memiliki judul dan keterangan sumbu yang jelas.

import matplotlib.pyplot as plt

bulan = ["Januari", "Februari", "Maret", "April"]
penjualan = [20, 25, 23, 30]

plt.plot(bulan, penjualan, marker="o", label="Penjualan")

plt.title("Grafik Penjualan Bulanan")
plt.xlabel("Bulan")
plt.ylabel("Jumlah Produk")
plt.legend()
plt.grid()

plt.show()

X labelMenjelaskan data pada sumbu X.
Y labelMenjelaskan data pada sumbu Y.
LegendMenjelaskan seri data jika terdapat keterangan.
GridMembantu memperkirakan nilai pada grafik.

Bagian 11

🔎 Cara Membaca dan Menarik Kesimpulan

Membuat grafik adalah langkah pertama. Langkah berikutnya adalah membaca grafik dengan teliti.

Gunakan pola sederhana

  1. Lihat kategori atau sumbu. Pahami apa yang ditampilkan pada X dan Y.
  2. Cari nilai tertinggi. Data mana yang paling besar?
  3. Cari nilai terendah. Data mana yang paling kecil?
  4. Perhatikan perubahan. Apakah data naik, turun, atau berfluktuasi?
  5. Bandingkan. Apakah terdapat perbedaan yang jelas?
  6. Tulis kesimpulan berdasarkan data. Jangan menambahkan informasi yang tidak terlihat pada grafik.

Contoh kesimpulan

Jika grafik penjualan menunjukkan Januari 20, Februari 25, Maret 23, April 30, Mei 35, dan Juni 32, maka contoh kesimpulannya:

  • Penjualan tertinggi terjadi pada bulan Mei dengan 35 produk.
  • Penjualan meningkat dari Januari ke Februari, kemudian sedikit menurun pada Maret.
  • Setelah Maret, penjualan meningkat sampai Mei lalu sedikit menurun pada Juni.
Hindari kesimpulan berlebihan: Jika grafik hanya menunjukkan penjualan meningkat, jangan langsung menyatakan penyebabnya tanpa data pendukung.

🚀 Proyek Mini — 3 Visualisasi dari Satu Dataset

Buat minimal 3 visualisasi dari dataset yang diberikan guru. Setiap grafik harus memiliki tujuan yang jelas.

Ketentuan proyek

  1. Gunakan dataset dari guru.
  2. Pilih minimal tiga data yang dapat divisualisasikan.
  3. Buat satu grafik batang.
  4. Buat satu grafik garis.
  5. Buat satu scatter plot.
  6. Berikan judul dan label sumbu pada setiap grafik.
  7. Tulis minimal tiga kesimpulan berdasarkan grafik.

Contoh dataset

Maret235115
April307140

Contoh kode lengkap

import matplotlib.pyplot as plt

bulan = ["Januari", "Februari", "Maret", "April", "Mei", "Juni"]
penjualan = [20, 25, 23, 30, 35, 32]
biaya_iklan = [5, 6, 5, 7, 8, 7]
pengunjung = [100, 120, 115, 140, 160, 150]

# 1. Grafik Batang
plt.bar(bulan, penjualan)
plt.title("Penjualan per Bulan")
plt.xlabel("Bulan")
plt.ylabel("Penjualan")
plt.xticks(rotation=30)
plt.show()

# 2. Grafik Garis
plt.plot(bulan, penjualan, marker="o")
plt.title("Perkembangan Penjualan")
plt.xlabel("Bulan")
plt.ylabel("Penjualan")
plt.grid()
plt.xticks(rotation=30)
plt.show()

# 3. Scatter Plot
plt.scatter(biaya_iklan, penjualan)
plt.title("Biaya Iklan dan Penjualan")
plt.xlabel("Biaya Iklan")
plt.ylabel("Penjualan")
plt.grid()
plt.show()

Menulis 3 kesimpulan

Kesimpulan 1Jelaskan informasi utama dari grafik batang.
Kesimpulan 2Jelaskan pola perubahan dari grafik garis.
Kesimpulan 3Jelaskan pola hubungan yang terlihat pada scatter plot.
Contoh: “Penjualan tertinggi terjadi pada bulan Mei dengan 35 unit.” Ini merupakan kesimpulan yang langsung didukung oleh data.
