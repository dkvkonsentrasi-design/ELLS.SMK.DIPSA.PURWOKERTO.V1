Bagian 3

🧩 Mengenal Fungsi Python

Fungsi adalah blok kode yang dibuat untuk melakukan pekerjaan tertentu. Fungsi dapat dipanggil berkali-kali tanpa harus menulis ulang seluruh kodenya.

Mengapa fungsi diperlukan?

♻️ Dapat digunakan kembaliKode cukup dibuat sekali lalu dapat dipanggil berkali-kali.
🧹 Kode lebih rapiProgram besar dapat dibagi menjadi bagian-bagian kecil.
🔎 Mudah dipahamiNama fungsi dapat menjelaskan pekerjaan yang dilakukan.
🛠️ Mudah diperbaikiJika ada kesalahan pada satu pekerjaan, kita dapat memperbaiki fungsi tersebut.

Contoh tanpa fungsi

print("Halo Andi")
print("Halo Budi")
print("Halo Citra")

Contoh menggunakan fungsi

def sapa(nama):
    print("Halo", nama)

sapa("Andi")
sapa("Budi")
sapa("Citra")
Perhatikan: Logika sapaan hanya dibuat sekali. Fungsi sapa() kemudian dipanggil dengan nama yang berbeda.

📥 Parameter dan Argumen

Parameter adalah variabel yang disiapkan di dalam definisi fungsi. Argumen adalah nilai yang diberikan ketika fungsi dipanggil.

def sapa(nama):      # nama adalah parameter
    print("Halo", nama)

sapa("Dina")          # "Dina" adalah argumen
sapa("Eko")

Fungsi dengan dua parameter

def luas_persegi_panjang(panjang, lebar):

luas_persegi_panjang(10, 5)

panjang dan lebar adalah parameter. Angka 10 dan 5 adalah argumen.

Bagian 6

↩️ Fungsi dengan Return

return digunakan untuk mengembalikan sebuah nilai dari fungsi kepada bagian program yang memanggilnya.

print()return
Menampilkan hasil ke layar.Mengembalikan hasil dari fungsi.
Hasil tidak otomatis disimpan ke variabel.Hasil dapat disimpan dalam variabel.
Cocok untuk menampilkan informasi.Cocok untuk hasil yang akan diproses lagi.

Contoh fungsi dengan return

def tambah(a, b):
    hasil = a + b
    return hasil

jumlah = tambah(10, 5)
print("Hasil:", jumlah)

Alurnya: 10 dan 5 masuk ke fungsi → dihitung → hasil 15 dikembalikan → disimpan dalam jumlah.

Return dapat digunakan dalam perhitungan berikutnya

def luas_persegi(sisi):
    return sisi * sisi

hasil_luas = luas_persegi(8)
hasil_dua_kali = hasil_luas * 2

print("Luas:", hasil_luas)
print("Dua kali luas:", hasil_dua_kali)
Ingat: Untuk fungsi yang menghasilkan nilai dan hasilnya masih akan digunakan oleh program, return biasanya lebih berguna daripada hanya print().
Bagian 7

📐 Praktik 1 — Fungsi Menghitung Luas

Kita dapat membuat fungsi khusus untuk menghitung luas beberapa bangun datar.

Luas persegi

Rumus: sisi × sisi.

def luas_persegi(sisi):
    return sisi * sisi

luas = luas_persegi(6)
print("Luas persegi:", luas)

Luas persegi panjang

Rumus: panjang × lebar.

def luas_persegi_panjang(panjang, lebar):
    return panjang * lebar

luas = luas_persegi_panjang(10, 4)
print("Luas persegi panjang:", luas)

Luas lingkaran

Rumus: π × r × r.

import math

def luas_lingkaran(jari_jari):
    return math.pi * jari_jari ** 2

luas = luas_lingkaran(7)
print("Luas lingkaran:", luas)
Konsep penting: Satu fungsi sebaiknya memiliki satu tujuan yang jelas. Misalnya luas_persegi() fokus menghitung luas persegi.

📏 Praktik 2 — Fungsi Menghitung Keliling

Keliling persegi

Rumus: 4 × sisi.

def keliling_persegi(sisi):

print("Keliling:", keliling_persegi(6))

Keliling persegi panjang

Rumus: 2 × (panjang + lebar).

def keliling_persegi_panjang(panjang, lebar):
    return 2 * (panjang + lebar)

print("Keliling:", keliling_persegi_panjang(10, 4))

Keliling lingkaran

Rumus: 2 × π × r.

import math

def keliling_lingkaran(jari_jari):
    return 2 * math.pi * jari_jari

print("Keliling:", keliling_lingkaran(7))
Latihan berpikir: Setiap fungsi menerima input, melakukan satu perhitungan, lalu mengembalikan hasil.
Bagian 9

📊 Praktik 3 — Fungsi Menghitung Rata-rata

Rata-rata dihitung dengan jumlah seluruh data ÷ jumlah data.

Versi menggunakan list

def hitung_rata_rata(nilai):
    total = sum(nilai)
    jumlah_data = len(nilai)
    return total / jumlah_data

data = [80, 75, 90, 85, 70]
rata_rata = hitung_rata_rata(data)

print("Rata-rata:", rata_rata)

Fungsi menerima sebuah list nilai. sum() menghitung total dan len() menghitung jumlah data.

Versi aman untuk list kosong

def hitung_rata_rata(nilai):
    if len(nilai) == 0:
        return 0
    return sum(nilai) / len(nilai)

data = [80, 75, 90]
print("Rata-rata:", hitung_rata_rata(data))
Mengapa perlu pemeriksaan? Jika list kosong, pembagian dengan len(nilai) akan menghasilkan pembagian dengan nol. Pemeriksaan membuat fungsi lebih aman.

🏅 Praktik 4 — Fungsi Menentukan Predikat Nilai

Fungsi juga dapat berisi percabangan. Kita dapat mengubah nilai menjadi predikat.

Rentang NilaiPredikat

Di bawah 60E
def tentukan_predikat(nilai):
    if nilai >= 90:
        return "A"
    elif nilai >= 80:
        return "B"
    elif nilai >= 70:
        return "C"
    elif nilai >= 60:
        return "D"
    else:
        return "E"

print(tentukan_predikat(92))
print(tentukan_predikat(76))
print(tentukan_predikat(55))

Python memeriksa kondisi dari atas ke bawah dan menggunakan kondisi pertama yang benar.

Menentukan keterangan lulus

def keterangan_kelulusan(nilai):
    if nilai >= 75:
        return "Lulus"
    return "Tidak Lulus"

nilai = 82
print(keterangan_kelulusan(nilai))
Perhatikan: Fungsi dengan return dapat digunakan sebagai bagian dari fungsi atau program lain.

🎯 Proyek: Mini Library Matematika

Buat sebuah Mini Library Matematika yang memiliki minimal 5 fungsi. Setiap fungsi harus mempunyai tujuan jelas dan dapat digunakan kembali.

Target minimal fungsi

  1. luas_persegi(sisi)
  2. luas_persegi_panjang(panjang, lebar)
  3. keliling_persegi(sisi)
  4. keliling_persegi_panjang(panjang, lebar)
  5. hitung_rata_rata(nilai)

Bonus: tambahkan luas_lingkaran(), keliling_lingkaran(), dan tentukan_predikat().

Langkah 1–5

  1. Buat fungsi luas persegi.
  2. Buat fungsi luas persegi panjang.
  3. Buat fungsi keliling persegi.
  4. Buat fungsi keliling persegi panjang.
  5. Buat fungsi rata-rata yang aman untuk list kosong.

Kode lengkap Mini Library

# ==========================================
# MINI LIBRARY MATEMATIKA
# ==========================================

def luas_persegi(sisi):
    return sisi * sisi

def luas_persegi_panjang(panjang, lebar):
    return panjang * lebar

def keliling_persegi(sisi):
    return 4 * sisi

def keliling_persegi_panjang(panjang, lebar):
    return 2 * (panjang + lebar)

def hitung_rata_rata(nilai):
    if len(nilai) == 0:
        return 0
    return sum(nilai) / len(nilai)

def luas_lingkaran(jari_jari):
    import math
    return math.pi * jari_jari ** 2

def keliling_lingkaran(jari_jari):
    import math
    return 2 * math.pi * jari_jari

def tentukan_predikat(nilai):
    if nilai >= 90:
        return "A"
    elif nilai >= 80:
        return "B"
    elif nilai >= 70:
        return "C"
    elif nilai >= 60:
        return "D"
    else:
        return "E"

# Pengujian
nilai_siswa = [80, 75, 90, 85, 70]

print("=== MINI LIBRARY MATEMATIKA ===")
print("Luas persegi:", luas_persegi(6))
print("Luas persegi panjang:", luas_persegi_panjang(10, 4))
print("Keliling persegi:", keliling_persegi(6))
print("Keliling persegi panjang:", keliling_persegi_panjang(10, 4))
print("Luas lingkaran:", luas_lingkaran(7))
print("Keliling lingkaran:", keliling_lingkaran(7))
print("Rata-rata nilai:", hitung_rata_rata(nilai_siswa))
print("Predikat rata-rata:", tentukan_predikat(
    hitung_rata_rata(nilai_siswa)
))

📝 5 Latihan Soal

Soal 1. Apa yang dimaksud dengan fungsi dalam Python?
Lihat pedoman jawaban
Fungsi adalah blok kode untuk melakukan pekerjaan tertentu dan dapat dipanggil kembali sehingga kode dapat digunakan kembali.
Soal 2. Apa fungsi kata kunci def?
Lihat jawaban
def digunakan untuk mendefinisikan atau membuat sebuah fungsi.
Soal 3. Pada def tambah(a, b): return a + b, apa yang dimaksud dengan a dan b?
Lihat jawaban
a dan b adalah parameter fungsi.
Soal 4. Apa perbedaan print() dan return?
Lihat pedoman jawaban
print() menampilkan informasi ke layar, sedangkan return mengembalikan nilai dari fungsi sehingga dapat disimpan atau diproses kembali.
Soal 5. Tentukan output def kuadrat(x): return x*x; print(kuadrat(5)).
Lihat jawaban
25, karena fungsi mengembalikan 5 × 5.
