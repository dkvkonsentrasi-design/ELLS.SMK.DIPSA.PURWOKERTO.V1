Bagian 3

🧠 Apa Itu Percabangan?

Percabangan adalah struktur program yang digunakan ketika komputer harus mengambil keputusan berdasarkan suatu kondisi.

Dalam kehidupan sehari-hari, kita sering membuat keputusan seperti:

  • Jika hujan, maka membawa payung.
  • Jika baterai HP habis, maka mengisi daya.
  • Jika nilai mencapai batas tertentu, maka siswa dinyatakan lulus.

Jalankan perintah

Python menggunakan if, elif, dan else untuk membuat keputusan. Dalam satu rangkaian if–elif–else, Python memeriksa kondisi dari atas ke bawah dan menjalankan blok yang sesuai. Jika semua kondisi bernilai salah, bagian else dapat dijalankan. citeturn0search0turn0search3

elifSingkatan dari else if, digunakan untuk memeriksa kondisi berikutnya.
elseDijalankan jika kondisi sebelumnya tidak terpenuhi.
IndentasiSpasi di awal baris yang menunjukkan blok kode mana yang termasuk dalam kondisi.
Bagian 4

🔹 Percabangan if

Bentuk paling sederhana adalah if. Artinya: jika kondisi benar, jalankan perintah.

Contoh sederhana

nilai = 80

if nilai >= 75:
    print("Nilai memenuhi batas lulus.")

Bagaimana Python membacanya?

  1. Variabel nilai berisi angka 80.
  2. Python memeriksa apakah nilai >= 75.
  3. 80 memang lebih besar atau sama dengan 75.
  4. Kondisi bernilai True.
  5. Python menjalankan print().
Perhatikan tanda titik dua: Setelah kondisi if harus ada tanda :. Baris perintah di bawahnya juga harus diberi indentasi.

Contoh jika kondisi tidak terpenuhi

nilai = 60

if nilai >= 75:
    print("Lulus")

Pada contoh tersebut tidak ada output karena kondisi nilai >= 75 bernilai False. Jika kita ingin memberi perintah saat kondisi salah, gunakan else.

Bagian 5

🔹 Percabangan if–else

if–else digunakan ketika ada dua kemungkinan utama: kondisi benar atau kondisi salah.

nilai = 60

if nilai >= 75:
    print("Lulus")
else:
    print("Tidak lulus")

Cara berpikirnya

KondisiHasil
Nilai ≥ 75Lulus
Nilai < 75Tidak lulus
Analogi: Bayangkan pintu dengan dua pilihan. Jika syarat terpenuhi, masuk melalui pintu A. Jika tidak terpenuhi, masuk melalui pintu B. Program tidak menjalankan kedua pilihan sekaligus.
Bagian 6

🔹 Percabangan if–elif–else

Jika program mempunyai lebih dari dua kemungkinan, kita dapat menggunakan elif.

nilai = 86

if nilai >= 90:
    print("Predikat A")
elif nilai >= 80:
    print("Predikat B")
elif nilai >= 70:
    print("Predikat C")
else:
    print("Predikat D")

Karena nilai adalah 86:

  1. 86 >= 90 → salah.
  2. 86 >= 80 → benar.
  3. Python menjalankan print("Predikat B").
  4. Python tidak perlu memeriksa cabang berikutnya.
Penting: Urutan kondisi berpengaruh. Letakkan kondisi dari batas yang paling tinggi ke yang lebih rendah ketika menentukan rentang nilai seperti contoh di atas.
Bagian 7

🔍 Operator Perbandingan

Operator perbandingan digunakan untuk membuat kondisi. Hasil perbandingan adalah nilai Boolean: True atau False.

OperatorArtiContohHasil
==sama dengan5 == 5True
!=tidak sama dengan5 != 3True
>lebih besar8 > 5True
<lebih kecil3 < 5True
>=lebih besar atau sama dengan75 >= 75True
<=lebih kecil atau sama dengan70 <= 75True
Jangan tertukar: = digunakan untuk memberikan nilai kepada variabel, sedangkan == digunakan untuk membandingkan dua nilai.
umur = 17

print(umur >= 17)
print(umur == 17)
print(umur < 17)
Bagian 8

🧩 Operator Logika: and, or, not

Operator logika digunakan ketika sebuah keputusan membutuhkan lebih dari satu kondisi.

OperatorMakna mudahContoh
andsemua kondisi harus benarnilai >= 75 and kehadiran >= 80
orsalah satu kondisi benar sudah cukuphari == "Sabtu" or hari == "Minggu"
notmembalik nilai benar/salahnot terlambat

Contoh and

nilai = 80
kehadiran = 90

if nilai >= 75 and kehadiran >= 80:
    print("Memenuhi syarat kelulusan")

Syarat di atas harus terpenuhi keduanya. Jika nilai cukup tetapi kehadiran kurang, kondisi keseluruhan bernilai False.

Contoh or

hari = "Minggu"

if hari == "Sabtu" or hari == "Minggu":
    print("Hari libur")
Bagian 9

🌳 Percabangan Bertingkat

Percabangan bertingkat adalah kondisi yang memiliki percabangan lain di dalamnya. Struktur ini berguna ketika keputusan kedua hanya perlu diperiksa setelah keputusan pertama terpenuhi.

Contoh sederhana

nilai = 85

if nilai >= 75:
    print("Nilai memenuhi batas lulus.")

    if nilai >= 90:
        print("Predikat A")
    else:
        print("Belum mencapai predikat A")
else:
    print("Tidak lulus")

Penjelasan langkah demi langkah

  1. Program memeriksa apakah nilai minimal 75.
  2. Jika tidak, program langsung menampilkan “Tidak lulus”.
  3. Jika ya, program masuk ke percabangan di dalamnya.
  4. Program kemudian memeriksa apakah nilai minimal 90.
  5. Jika ya, tampilkan “Predikat A”. Jika tidak, tampilkan “Belum mencapai predikat A”.
Kapan menggunakan percabangan bertingkat? Gunakan ketika ada keputusan yang memang bergantung pada keputusan sebelumnya. Jika semua kondisi berdiri sendiri dalam satu urutan, if–elif–else biasanya lebih sederhana.

Kesalahan yang sering terjadi

1. Lupa :Setiap if, elif, dan else membutuhkan titik dua.
2. Indentasi salahKode di dalam kondisi harus menjorok secara konsisten.
3. Salah memakai =Gunakan == untuk membandingkan nilai.
4. Urutan kondisi keliruKondisi yang terlalu umum di awal bisa membuat cabang berikutnya tidak pernah dijalankan.
Bagian 10

🎯 Proyek Mini: Program Penentu Kelulusan Siswa

Setelah memahami if, elif, else, operator perbandingan, dan operator logika, sekarang kita membuat program yang lebih lengkap.

10.1 Tujuan proyek

Program akan meminta pengguna memasukkan nama dan nilai. Setelah itu program menentukan predikat dan keterangan lulus/tidak lulus.

10.2 Input

  • Nama siswa
  • Nilai siswa

10.3 Aturan nilai

Rentang NilaiPredikatKeterangan
90–100ALulus
80–89BLulus
75–79CLulus
0–74DTidak Lulus

10.4 Kode program lengkap

nama = input("Masukkan nama siswa: ")
nilai = float(input("Masukkan nilai siswa: "))

if nilai >= 90:
    predikat = "A"
    keterangan = "Lulus"
elif nilai >= 80:
    predikat = "B"
    keterangan = "Lulus"
elif nilai >= 75:
    predikat = "C"
    keterangan = "Lulus"
else:
    predikat = "D"
    keterangan = "Tidak Lulus"

print("\n===== HASIL PENILAIAN =====")
print("Nama       :", nama)
print("Nilai      :", nilai)
print("Predikat   :", predikat)
print("Keterangan :", keterangan)

10.5 Memahami kode baris demi baris

1
nama = input(...) meminta pengguna memasukkan nama. Hasil input disimpan dalam variabel nama.
2
float(input(...)) mengambil nilai dan mengubahnya menjadi angka desimal sehingga dapat dibandingkan dengan batas nilai.
3
if nilai >= 90 memeriksa apakah nilai termasuk predikat A.
4
Jika tidak, elif memeriksa batas nilai berikutnya.
5
Jika tidak ada kondisi sebelumnya yang benar, else menetapkan predikat D dan status Tidak Lulus.
6
Empat perintah print() terakhir menampilkan hasil kepada pengguna.

10.6 Contoh hasil

Masukkan nama siswa: Andi
Masukkan nilai siswa: 86

===== HASIL PENILAIAN =====
Nama       : Andi
Nilai      : 86.0
Predikat   : B
Keterangan : Lulus

10.7 Versi lebih aman: validasi nilai

Program di atas masih menerima nilai di luar rentang 0–100. Kita dapat menambahkan percabangan untuk mengecek apakah input valid.

nama = input("Masukkan nama siswa: ")
nilai = float(input("Masukkan nilai siswa: "))

if nilai < 0 or nilai > 100:
    print("Nilai tidak valid. Masukkan nilai 0 sampai 100.")
else:
    if nilai >= 90:
        predikat = "A"
        keterangan = "Lulus"
    elif nilai >= 80:
        predikat = "B"
        keterangan = "Lulus"
    elif nilai >= 75:
        predikat = "C"
        keterangan = "Lulus"
    else:
        predikat = "D"
        keterangan = "Tidak Lulus"

    print("\n===== HASIL PENILAIAN =====")
    print("Nama       :", nama)
    print("Nilai      :", nilai)
    print("Predikat   :", predikat)
    print("Keterangan :", keterangan)
Yang dipelajari dari versi ini: program melakukan pemeriksaan pertama terhadap validitas nilai. Jika nilai valid, barulah program menjalankan percabangan penentuan predikat. Ini adalah contoh nyata percabangan bertingkat.

🛠️ Lima Tugas Praktik

Tugas 1 — Menentukan Bilangan Positif, Negatif, atau Nol

Buat program yang menerima satu angka. Jika angka lebih dari 0 tampilkan “Positif”, jika kurang dari 0 tampilkan “Negatif”, dan jika sama dengan 0 tampilkan “Nol”.

Output: kode program + screenshot hasil di Google Colab.

Tugas 2 — Menentukan Bilangan Ganjil atau Genap

Buat program yang menerima sebuah bilangan bulat. Gunakan operator modulus % untuk menentukan apakah bilangan tersebut genap atau ganjil.

Petunjuk: bilangan genap jika angka % 2 == 0.

Output: notebook Colab yang dapat dijalankan tanpa error.

Tugas 3 — Konversi Nilai Menjadi Predikat

Buat program yang menerima nilai 0–100 kemudian menentukan predikat:

  • 90–100 = A
  • 80–89 = B
  • 75–79 = C
  • 0–74 = D

Tambahkan validasi agar nilai di bawah 0 atau di atas 100 dianggap tidak valid.

Tugas 4 — Seleksi Siswa Mengikuti Kegiatan

Buat program dengan input nilai dan kehadiran. Siswa boleh mengikuti kegiatan jika nilai minimal 75 dan kehadiran minimal 80%.

Output: “Boleh mengikuti kegiatan” atau “Belum memenuhi syarat”.

Tugas 5 — Program Penentu Kelulusan Siswa

Kembangkan proyek mini menjadi program yang menerima:

  • nama siswa
  • nilai
  • kehadiran

Siswa dinyatakan lulus jika nilai minimal 75 dan kehadiran minimal 80%. Program juga harus menentukan predikat A, B, C, atau D.

Output yang wajib ditampilkan: nama, nilai, kehadiran, predikat, dan keterangan lulus/tidak lulus.
