Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa diharapkan mampu:

  • Menjelaskan pengertian dan fungsi mockup.
  • Memahami konsep Smart Object pada Photoshop.
  • Memasukkan desain ke dalam mockup.
  • Mengubah ukuran dan posisi desain menggunakan Transform.
  • Menyesuaikan desain mengikuti bidang menggunakan Perspective.
  • Mengatur posisi dan proporsi desain agar terlihat realistis.
  • Menyesuaikan pencahayaan dan kontras secara sederhana.
  • Membuat mockup pada T-shirt, poster, kemasan, mug, atau media lainnya.
  • Menyimpan file kerja agar dapat diedit kembali.

1. Pengertian Mockup

Mockup adalah visualisasi yang menunjukkan bagaimana sebuah desain akan terlihat ketika diterapkan pada media atau benda nyata.

Contohnya, kita memiliki desain logo atau desain grafis dalam bentuk file digital. Desain tersebut belum tentu mudah dibayangkan ketika diterapkan pada T-shirt. Dengan mockup, desain dapat ditampilkan seolah-olah sudah tercetak pada T-shirt.

Desain Asli

File desain seperti logo, poster, ilustrasi, label, atau artwork yang masih berada pada canvas.

Mockup

Visualisasi desain setelah ditempatkan pada benda atau media tertentu sehingga lebih mudah dibayangkan.

Sederhananya: desain adalah “apa yang dibuat”, sedangkan mockup menunjukkan “seperti apa desain tersebut ketika digunakan atau diterapkan”.

2. Fungsi Mockup

Mockup banyak digunakan dalam dunia desain karena dapat membantu menjelaskan hasil desain kepada klien, guru, teman satu tim, atau calon pengguna.

Presentasi

Membuat desain terlihat lebih nyata ketika dipresentasikan.

Evaluasi

Membantu melihat apakah ukuran, posisi, warna, dan komposisi desain sudah sesuai.

Promosi

Menampilkan produk atau hasil desain dalam bentuk visual yang lebih menarik.

Portofolio

Membantu desainer menunjukkan bagaimana karya mereka dapat diterapkan pada berbagai media.

Contoh penggunaan

  • Logo pada T-shirt.
  • Poster pada dinding.
  • Desain label pada kemasan.
  • Logo pada mug.
  • Desain cover pada buku.
  • Desain layar aplikasi pada smartphone.
  • Desain billboard atau banner.

3. Smart Object

Smart Object adalah fitur Photoshop yang membantu menjaga informasi asli dari sebuah layer sehingga layer dapat ditransformasi atau diedit dengan lebih aman.

Mengapa Smart Object penting untuk mockup?

Dalam workflow mockup, desain biasanya dimasukkan ke dalam Smart Object. Ketika Smart Object tersebut dibuka, kita dapat mengganti isi desain tanpa harus membangun ulang seluruh mockup.

Konsep sederhana

File mockup: T-shirt.psd
↓
Smart Object: “Your Design Here”
↓
Edit Smart Object: masukkan desain siswa
↓
Save: kembali ke file mockup
↓
Hasil: desain muncul pada T-shirt

Cara membuat Smart Object dari layer

  1. Pilih layer yang ingin digunakan.
  2. Klik kanan pada layer.
  3. Pilih opsi Convert to Smart Object jika tersedia.
Catatan: nama menu dapat sedikit berbeda tergantung versi Photoshop. Intinya, cari perintah untuk mengubah layer menjadi Smart Object.

Cara mengenali Smart Object

Pada panel Layers, thumbnail Smart Object biasanya memiliki tanda kecil pada ikon layer. Jika belum yakin, klik kanan layer dan periksa apakah tersedia pilihan untuk mengedit isi Smart Object.

4. Transform

Transform digunakan untuk mengubah ukuran, posisi, rotasi, dan bentuk suatu elemen. Transform sangat penting karena desain harus ditempatkan sesuai ukuran dan posisi media mockup.

Jenis transform yang sering digunakan

Transform Fungsi Contoh
Scale Mengubah ukuran. Mengecilkan logo agar sesuai dengan dada T-shirt.
Rotate Memutar objek. Mengikuti kemiringan permukaan mockup.
Move Memindahkan posisi. Memindahkan desain ke tengah kemasan.
Skew Mengubah kemiringan sisi objek. Menyesuaikan desain dengan bidang miring.
Distort Mengubah sudut/pojok secara lebih bebas. Mengikuti bidang yang bentuknya tidak lurus.
Perspective Mengubah bentuk agar mengikuti perspektif. Desain pada poster yang terlihat miring dari sudut tertentu.

Shortcut umum

Pada banyak versi Photoshop, Ctrl + T (Windows) atau Cmd + T (Mac) membuka Free Transform. Pastikan layer yang benar sudah dipilih sebelum melakukan transformasi.

5. Perspective

Perspective digunakan ketika desain ditempatkan pada bidang yang tidak terlihat lurus dari sudut pandang kamera. Tujuannya agar desain tampak mengikuti arah bidang media.

Contoh kasus

  • Poster yang difoto dari sudut samping.
  • Label kemasan yang permukaannya miring.
  • Desain pada papan atau dinding dengan perspektif.
  • Desain pada buku yang difoto dari sudut tertentu.

Prinsip sederhana

Jika bidang media terlihat mengecil ke satu arah, desain yang ditempatkan di atasnya juga perlu mengikuti arah tersebut. Jangan memaksa desain tetap berbentuk persegi sempurna jika permukaan mockup terlihat miring.

Jangan berlebihan menggunakan Perspective atau Distort. Jika perubahan terlalu ekstrem, desain dapat terlihat tidak realistis.

6. Memasukkan Desain ke Mockup

Ada dua kondisi yang umum ditemui. Pertama, mockup sudah menyediakan Smart Object. Kedua, kita membuat mockup sederhana secara manual dari sebuah foto.

A. Jika mockup sudah memiliki Smart Object

  1. Buka file mockup PSD.
  2. Cari layer yang bertuliskan seperti Place Your Design, Your Design Here, atau nama serupa.
  3. Double-click thumbnail Smart Object.
  4. Tab atau dokumen Smart Object akan terbuka.
  5. Masukkan desain Anda ke dalam dokumen tersebut.
  6. Atur ukuran dan posisi desain.
  7. Simpan Smart Object.
  8. Kembali ke dokumen mockup.
  9. Photoshop akan memperbarui tampilan desain pada mockup.

B. Jika membuat mockup sederhana secara manual

  1. Buka foto media yang akan digunakan.
  2. Masukkan desain sebagai layer baru.
  3. Ubah desain menjadi Smart Object bila diperlukan.
  4. Atur ukuran dengan Transform.
  5. Atur posisi sesuai bidang media.
  6. Gunakan Perspective, Distort, atau Warp jika diperlukan.
  7. Gunakan Blend Mode atau Opacity secara hati-hati.
  8. Tambahkan penyesuaian pencahayaan dan bayangan sederhana.

7. Menyesuaikan Ukuran dan Posisi

Ukuran desain harus masuk akal dibandingkan ukuran benda. Logo pada mug tentu tidak boleh sebesar seluruh permukaan mug jika konsepnya hanya logo kecil.

Hal yang perlu diperhatikan

  • Ukuran media secara keseluruhan.
  • Area cetak yang tersedia.
  • Proporsi desain.
  • Jarak desain dari tepi media.
  • Posisi desain terhadap kamera.
  • Arah permukaan media.

Tips: bandingkan desain dengan benda di sekitarnya. Jika logo terlihat terlalu besar atau terlalu kecil dibandingkan skala benda, sesuaikan kembali.

8. Menyesuaikan Pencahayaan Secara Sederhana

Salah satu kesalahan pemula adalah membuat desain terlalu “menempel” seperti gambar datar. Agar lebih menyatu dengan foto, kita dapat menyesuaikan opacity, blend mode, kontras, dan bayangan secara sederhana.

Teknik 1 — Opacity

Jika desain terlihat terlalu kuat, kurangi opacity sedikit. Namun jangan terlalu rendah karena desain dapat menjadi sulit terlihat.

Teknik 2 — Blend Mode

Beberapa blend mode dapat membantu desain berinteraksi dengan tekstur dan pencahayaan media. Contohnya Multiply dapat digunakan dalam kondisi tertentu agar tekstur gelap pada permukaan tetap terlihat. Gunakan sesuai kebutuhan karena hasilnya tergantung foto.

Teknik 3 — Adjustment Layer

Gunakan Brightness/Contrast, Levels, Curves, Hue/Saturation, atau adjustment lain secara ringan untuk menyesuaikan desain dengan suasana foto.

Teknik 4 — Bayangan sederhana

Pada beberapa mockup manual, bayangan lembut dapat membantu desain terlihat memiliki kedalaman. Gunakan layer terpisah dan jangan membuat bayangan terlalu gelap.

Teknik 5 — Tekstur media

Jika media memiliki tekstur kain, kertas, plastik, atau permukaan lainnya, jangan selalu menutup tekstur tersebut sepenuhnya. Dalam mockup yang realistis, karakter permukaan biasanya masih dapat terlihat.

Prinsip: penyesuaian pencahayaan harus halus. Tujuannya bukan membuat efek sebanyak mungkin, tetapi membuat desain terasa menyatu dengan media.

9. Praktik Membuat Mockup di Photoshop

Berikut langkah lengkap yang dapat digunakan untuk latihan mockup sederhana.

Pilih media

Tentukan media yang akan digunakan, misalnya T-shirt, mug, poster, kemasan, buku, tote bag, atau smartphone.

Siapkan foto/media

Gunakan foto dengan kualitas yang cukup dan bidang media terlihat jelas. Pastikan foto tidak terlalu buram atau terlalu gelap.

Siapkan desain

Pastikan desain sudah selesai dan memiliki ukuran yang sesuai. Desain dapat berupa logo, ilustrasi, poster, label, atau artwork.

Masukkan desain

Masukkan desain sebagai layer baru. Jika workflow membutuhkan fleksibilitas, ubah layer menjadi Smart Object.

Atur ukuran

Gunakan Free Transform untuk mengecilkan atau membesarkan desain. Pertahankan proporsi agar desain tidak berubah bentuk secara tidak sengaja.

Atur posisi

Pindahkan desain ke area yang sesuai. Perhatikan margin dari tepi dan hubungan dengan elemen pada media.

Sesuaikan perspektif

Jika permukaan media miring, gunakan Perspective, Distort, atau Warp sesuai kebutuhan. Cocokkan sudut desain dengan sudut permukaan.

Sesuaikan pencahayaan

Atur opacity, blend mode, kontras, dan warna secara ringan. Tujuannya agar desain terasa menjadi bagian dari media.

Tambahkan bayangan/tekstur bila diperlukan

Gunakan layer terpisah. Buat efek yang halus dan jangan menutupi desain secara berlebihan.

Bandingkan dengan foto asli

Sembunyikan dan tampilkan layer desain untuk memastikan perubahan yang dibuat memang membantu mockup terlihat lebih realistis.

Rapikan layer

Beri nama layer seperti Design, Shadow, Highlight, dan Background. Layer yang rapi memudahkan revisi.

Simpan file

Simpan file kerja sebagai PSD agar layer dan Smart Object tetap dapat diedit. Ekspor JPEG atau PNG jika membutuhkan file untuk presentasi atau publikasi.

10. Jenis Media untuk Mockup

Teknik dasar mockup dapat diterapkan pada banyak media. Setiap media memiliki karakteristik permukaan dan perspektif yang berbeda.

T-Shirt

Perhatikan lipatan kain, bentuk badan, dan posisi desain di area cetak.

Poster

Perhatikan bidang datar, sudut kamera, dan perspektif jika poster difoto dari samping.

Kemasan

Perhatikan beberapa sisi kemasan dan perubahan perspektif pada sudut-sudutnya.

Mug

Perhatikan permukaan melengkung dan posisi desain terhadap bentuk mug.

Tote Bag

Perhatikan lipatan kain dan area cetak agar desain tidak terlihat terlalu datar.

Buku

Perhatikan sudut cover, ketebalan buku, dan arah pencahayaan.

Semakin kompleks bentuk media, semakin banyak penyesuaian yang diperlukan. Mulailah dari bidang yang sederhana seperti poster atau T-shirt sebelum mencoba kemasan dan permukaan melengkung.

11. Proyek: Membuat Mockup Desain

Buat satu atau beberapa mockup yang menampilkan desain Anda pada media nyata.

Pilihan media proyek

Proyek A — T-Shirt

Tempatkan logo atau artwork pada bagian depan T-shirt.

Proyek B — Poster

Tampilkan poster pada dinding atau bidang tertentu menggunakan perspektif.

Proyek C — Kemasan

Tempatkan desain label atau identitas brand pada kemasan sederhana.

Proyek D — Mug

Tampilkan logo atau ilustrasi pada permukaan mug.

Contoh brief

Brand: DIPSA Creative
Produk: T-Shirt komunitas DKV
Gaya: Modern dan minimalis
Desain: Logo + tulisan “Creative Student”
Warna: Hitam, putih, marun
Media: T-Shirt warna netral

Langkah proyek

  1. Tentukan media mockup.
  2. Tentukan konsep dan target penggunaan.
  3. Siapkan desain final.
  4. Siapkan foto mockup.
  5. Masukkan desain menggunakan Smart Object atau layer terpisah.
  6. Atur ukuran dan posisi.
  7. Sesuaikan Perspective/Warp jika diperlukan.
  8. Sesuaikan pencahayaan, opacity, dan tekstur.
  9. Rapikan layer.
  10. Simpan PSD dan ekspor hasil akhir.

Checklist hasil akhir

  • Desain berada pada posisi yang tepat.
  • Ukuran desain terlihat proporsional.
  • Perspektif sesuai dengan media.
  • Desain tidak terlihat seperti gambar datar yang ditempel.
  • Tekstur atau pencahayaan media masih terlihat secara wajar.
  • Warna desain tidak terlalu berbeda dari kondisi pencahayaan foto.
  • Layer dan Smart Object tersusun rapi.
  • File PSD tersimpan.
  • File final sudah diekspor.

Kriteria penilaian proyek

Aspek Yang Dinilai
Konsep Kesesuaian desain dengan media yang dipilih.
Penempatan Posisi dan ukuran desain pada media.
Transform Kemampuan menyesuaikan ukuran, rotasi, dan bentuk.
Perspective Kesesuaian desain dengan sudut bidang media.
Realistis Kemampuan menyatukan desain dengan pencahayaan dan tekstur media.
Smart Object Pemanfaatan Smart Object dalam workflow.
Kerapian Organisasi layer dan file kerja.
Output Kualitas file PSD dan hasil ekspor.

12. Kesalahan Umum

Desain terlalu besar

Sesuaikan ukuran dengan skala benda dan area cetak yang masuk akal.

Desain terlalu datar

Sesuaikan perspektif, opacity, pencahayaan, atau tekstur secara halus.

Perspektif tidak sesuai

Ikuti arah bidang media. Jangan mempertahankan bentuk persegi jika permukaannya miring.

Warna terlalu terang

Perhatikan pencahayaan foto dan lakukan penyesuaian secara ringan.

Tekstur media hilang

Jangan menutup seluruh karakter permukaan jika ingin hasil lebih realistis.

Layer tidak rapi

Beri nama dan kelompokkan layer agar mudah melakukan revisi.

Ingat: mockup yang baik tidak harus memiliki banyak efek. Justru penyesuaian kecil yang tepat sering membuat hasil terlihat lebih realistis.

13. 5 Latihan Soal

Soal 1 — Apa yang dimaksud dengan mockup?

Jawaban: Mockup adalah visualisasi yang menunjukkan bagaimana sebuah desain akan terlihat ketika diterapkan pada media atau benda nyata.

Soal 2 — Mengapa Smart Object berguna dalam pembuatan mockup?

Jawaban: Smart Object membantu menjaga isi layer agar dapat diedit dan ditransformasi dengan lebih fleksibel. Pada template mockup, isi desain dapat diganti tanpa membangun ulang seluruh tampilan.

Soal 3 — Apa fungsi Transform dalam mockup?

Jawaban: Transform digunakan untuk mengubah ukuran, posisi, rotasi, dan bentuk desain agar sesuai dengan media mockup.

Soal 4 — Kapan Perspective diperlukan?

Jawaban: Perspective diperlukan ketika desain ditempatkan pada bidang yang terlihat miring atau memiliki sudut pandang tertentu sehingga desain perlu mengikuti arah bidang tersebut.

Soal 5 — Mengapa pencahayaan dan tekstur perlu disesuaikan?

Jawaban: Agar desain terlihat lebih menyatu dengan media dan tidak terlihat seperti gambar datar yang ditempel di atas foto.

14. 5 Tugas Praktik

Tugas 1 — Mockup T-Shirt

Buat desain logo atau artwork sederhana kemudian tampilkan pada T-shirt. Gunakan Transform untuk mengatur ukuran dan posisi serta sesuaikan pencahayaan secara sederhana.

Output: 1 mockup T-shirt + file PSD.

Tugas 2 — Mockup Poster

Buat sebuah poster kemudian tempatkan pada foto dinding atau papan. Gunakan Perspective atau Distort agar poster mengikuti sudut bidang.

Output: 1 mockup poster + file PSD.

Tugas 3 — Mockup Kemasan

Buat label sederhana untuk produk fiktif lalu tampilkan pada kemasan. Perhatikan ukuran, perspektif, warna, dan pencahayaan.

Output: 1 mockup kemasan + file PSD.

Tugas 4 — Mockup Mug

Buat desain logo atau ilustrasi untuk mug. Tempatkan desain pada permukaan mug dan lakukan penyesuaian agar terlihat mengikuti bentuk media.

Output: 1 mockup mug + file PSD.

Tugas 5 — Proyek Bebas

Pilih satu media lain seperti tote bag, buku, smartphone, botol, notebook, atau billboard. Buat mockup dengan memanfaatkan Smart Object, Transform, Perspective/Warp, dan penyesuaian pencahayaan sederhana.

Output: 1 mockup final + file PSD + penjelasan singkat proses.

15. Ringkasan

Mockup digunakan untuk menampilkan desain dalam konteks media nyata. Dengan mockup, desain logo, poster, kemasan, atau artwork dapat terlihat lebih mudah dipahami dan dipresentasikan.

  • Mockup menunjukkan penerapan desain pada media nyata.
  • Smart Object membantu membuat workflow lebih fleksibel.
  • Transform digunakan untuk mengatur ukuran, posisi, rotasi, dan bentuk.
  • Perspective membantu desain mengikuti sudut pandang bidang.
  • Ukuran desain harus sesuai dengan skala media.
  • Pencahayaan dan tekstur dapat disesuaikan agar hasil lebih realistis.
  • Layer yang rapi memudahkan revisi.
  • File PSD sebaiknya disimpan sebelum mengekspor hasil akhir.
Inti materi: membuat mockup bukan sekadar menempelkan gambar ke foto. Desain harus disesuaikan dengan ukuran, posisi, perspektif, bentuk, pencahayaan, dan karakter permukaan media agar hasilnya terlihat meyakinkan.
