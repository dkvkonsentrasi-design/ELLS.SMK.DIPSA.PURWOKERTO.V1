Tujuan Pembelajaran

Setelah mempelajari materi ini, siswa diharapkan mampu:

  • Menjelaskan pengertian typography dan perannya dalam desain grafis.
  • Menggunakan Type Tool untuk membuat teks di Photoshop.

  • Memilih font yang sesuai dengan tema desain.

Inti materi: Typography bukan sekadar memilih font yang bagus. Typography adalah cara mengatur huruf, ukuran, jarak, posisi, warna, dan hubungan antar-teks agar pesan dapat dibaca sekaligus terlihat menarik.

1. Pengertian Typography

Typography adalah seni dan teknik mengatur huruf atau teks agar informasi dapat disampaikan dengan jelas, nyaman dibaca, dan mempunyai tampilan visual yang sesuai dengan tujuan desain.

Dalam desain grafis, teks bukan hanya isi yang dibaca. Teks juga merupakan elemen visual. Sebuah judul yang besar dapat menarik perhatian, teks kecil dapat memberikan informasi tambahan, sedangkan pilihan font dapat memberikan kesan formal, modern, santai, elegan, atau kuat.

Mengapa typography penting?

1. Menyampaikan informasi

Typography membantu pembaca memahami isi desain dengan lebih cepat.

2. Menentukan karakter

Font dan pengaturan teks dapat memberikan suasana tertentu pada sebuah desain.

3. Menarik perhatian

Judul dan teks utama dapat dibuat lebih menonjol untuk mengarahkan perhatian.

4. Membuat desain terstruktur

Hierarchy membantu pembaca mengetahui mana informasi utama dan mana informasi pendukung.

Contoh sederhana

BELAJAR. BERKARYA. BERKEMBANG.
Typography dapat membuat sebuah kalimat menjadi elemen visual yang kuat.

Kalimat yang sama dapat memberikan kesan berbeda hanya dengan mengubah font, ukuran, jarak, warna, dan susunannya. Inilah alasan typography sangat penting dalam desain.

2. Type Tool

Type Tool digunakan untuk membuat dan mengedit teks di Photoshop. Type Tool biasanya ditandai dengan ikon huruf T.

Jenis Type Tool yang umum

  • Horizontal Type Tool — membuat teks secara horizontal.
  • Vertical Type Tool — membuat teks secara vertikal.
  • Horizontal Type Mask Tool — membuat selection berdasarkan bentuk teks.
  • Vertical Type Mask Tool — membuat selection teks secara vertikal.

Langkah membuat teks

1 Buka Photoshop dan buat dokumen baru atau buka gambar yang ingin diberi teks.
2 Pilih Type Tool atau tekan T.
3 Klik pada canvas untuk membuat Point Text, atau klik-drag untuk membuat area Paragraph Text.
4 Ketik teks yang diinginkan.
5 Pilih teks jika ingin mengubah font, ukuran, warna, atau pengaturan lainnya.
6 Gunakan Move Tool untuk mengatur posisi text layer jika diperlukan.
Tips: Biasakan membuat teks sebagai Text Layer. Jangan langsung mengubahnya menjadi raster jika belum diperlukan, karena Text Layer lebih mudah diedit.

3. Point Text dan Paragraph Text

Saat menggunakan Type Tool, ada dua cara dasar membuat teks: Point Text dan Paragraph Text.

Point Text Paragraph Text
Dibuat dengan satu klik pada canvas. Dibuat dengan klik-drag untuk membuat area teks.
Cocok untuk judul pendek, logo, label, atau kata utama. Cocok untuk paragraf dan teks yang lebih panjang.
Teks dapat memanjang sesuai jumlah karakter. Teks akan mengikuti batas area yang dibuat.
Praktis untuk headline. Lebih mudah digunakan untuk mengontrol blok teks.

Contoh Point Text

Misalnya kamu membuat poster dengan judul "FESTIVAL KREATIF". Klik satu kali pada canvas kemudian ketik judul. Ini cocok karena judul merupakan teks pendek.

Contoh Paragraph Text

Jika kamu ingin menambahkan deskripsi acara yang terdiri dari beberapa kalimat, klik-drag untuk membuat area teks. Teks akan berada di dalam area tersebut.

Rumus mudah:
Teks pendek / judul → Point Text
Teks panjang / paragraf → Paragraph Text

4. Font

Font adalah bentuk atau gaya visual huruf yang digunakan dalam teks. Pemilihan font harus mempertimbangkan isi pesan, target pembaca, media, dan karakter desain.

Kelompok font secara sederhana

Serif

Memiliki detail kecil atau "kaki" pada huruf. Sering memberikan kesan klasik, formal, editorial, atau elegan.

Sans Serif

Tidak mempunyai detail kaki. Sering memberikan kesan bersih, modern, sederhana, dan mudah digunakan dalam desain digital.

Script

Meniru gaya tulisan tangan atau kaligrafi. Dapat memberikan kesan personal, elegan, atau dekoratif.

Display

Dirancang untuk tampilan besar dan menarik perhatian. Cocok untuk judul, poster, atau headline tertentu.

Cara memilih font

  1. Tentukan tema desain.
  2. Tentukan target pembaca.
  3. Pilih font yang mudah dibaca.
  4. Gunakan font dekoratif secara hati-hati.
  5. Pastikan font mendukung karakter bahasa dan simbol yang digunakan.
Hindari: menggunakan terlalu banyak jenis font dalam satu desain. Terlalu banyak font dapat membuat desain terlihat tidak teratur dan membingungkan.

5. Font Size

Font size adalah ukuran huruf. Ukuran teks harus disesuaikan dengan tingkat kepentingan informasi dan ukuran media.

Contoh hierarchy ukuran

Judul utama

Gunakan ukuran paling besar agar menjadi titik perhatian pertama.

Subjudul

Lebih kecil dari judul tetapi tetap mudah terlihat.

Isi

Gunakan ukuran yang nyaman dibaca dalam jumlah teks yang lebih banyak.

Informasi tambahan

Dapat dibuat lebih kecil, tetapi tetap harus terbaca.

Kesalahan yang sering terjadi

Jangan menentukan ukuran hanya berdasarkan angka. Ukuran visual setiap font dapat berbeda. Dua font dengan ukuran yang sama belum tentu terlihat sama besar.

Tips: Selain melihat angka font size, lihat juga hasil visualnya. Pastikan judul benar-benar terlihat sebagai judul dan isi tetap nyaman dibaca.

6. Tracking

Tracking adalah pengaturan jarak secara keseluruhan antara karakter dalam sebuah teks atau bagian teks.

Tracking berbeda dengan kerning. Tracking biasanya diterapkan pada sekumpulan huruf, sedangkan kerning mengatur jarak antara pasangan huruf tertentu.

Contoh penggunaan tracking

  • Judul huruf kapital dapat diberi sedikit tambahan jarak agar terlihat lebih elegan.
  • Teks yang terlalu rapat dapat diberi tracking agar lebih nyaman dibaca.
  • Tracking dapat membantu membuat judul memiliki ruang visual yang lebih luas.

Tracking terlalu rapat

Huruf terlihat berhimpitan dan dapat mengurangi kenyamanan membaca.

Tracking terlalu lebar

Kata dapat terlihat terpecah dan hubungan antarhuruf menjadi terlalu jauh.

Gunakan tracking secara visual. Tidak ada satu angka yang selalu benar untuk semua font.

7. Leading

Leading adalah jarak vertikal antarbaris teks. Pengaturan leading sangat penting ketika menggunakan Paragraph Text atau teks yang terdiri dari beberapa baris.

Mengapa leading penting?

  • Leading terlalu kecil dapat membuat baris terlihat bertumpuk.
  • Leading terlalu besar dapat membuat paragraf terlihat terpecah.
  • Leading yang tepat membuat teks lebih nyaman dibaca.
Tips sederhana: Jika paragraf terasa "sesak", coba tambahkan jarak antarbaris. Jika setiap baris terasa terlalu jauh, kurangi leading.

Leading pada poster

Untuk poster, leading juga dapat digunakan sebagai elemen visual. Judul dengan dua atau tiga baris dapat dibuat lebih rapat untuk menghasilkan tampilan yang kuat, selama masih terbaca.

8. Alignment

Alignment adalah cara teks disejajarkan dalam sebuah area. Alignment yang tepat membuat desain terlihat teratur.

Alignment Karakter Contoh Penggunaan
Left Align Rapi dan mudah dibaca. Artikel, informasi, deskripsi.
Center Align Simetris dan menarik perhatian. Judul poster, undangan, headline.
Right Align Memberikan variasi arah visual. Informasi tertentu atau layout editorial.
Justify Rata kiri dan kanan. Blok paragraf tertentu.
Tips: Untuk teks panjang, left align biasanya lebih mudah dibaca. Center align cocok untuk teks pendek seperti judul atau undangan.

9. Hierarchy

Typography hierarchy adalah pengaturan tingkat kepentingan teks sehingga pembaca tahu informasi mana yang harus dilihat terlebih dahulu.

Contoh hierarchy

  1. Headline: informasi paling penting dan paling menarik perhatian.
  2. Subheadline: menjelaskan atau memperkuat headline.
  3. Body Text: memberikan penjelasan lebih lengkap.
  4. Caption/Informasi kecil: informasi tambahan.

Cara membuat hierarchy

Ukuran

Gunakan ukuran berbeda antara judul dan isi.

Ketebalan

Gunakan weight yang berbeda untuk membedakan tingkat informasi.

Warna

Warna dapat digunakan untuk menarik perhatian pada informasi tertentu.

Posisi

Informasi yang ditempatkan pada posisi strategis dapat menjadi perhatian pertama.

Prinsip mudah: Jika semua teks terlihat sama penting, berarti hierarchy belum cukup jelas. Buat satu elemen menjadi yang paling dominan, kemudian susun informasi pendukung di bawahnya.

10. Kombinasi Font

Menggunakan dua font dapat membuat desain lebih menarik, tetapi kombinasi harus dilakukan dengan hati-hati. Tujuannya adalah membuat font berbeda namun tetap terasa saling melengkapi.

Strategi kombinasi font

Serif + Sans Serif

Gunakan serif untuk judul dan sans serif untuk isi, atau sebaliknya.

Bold + Regular

Gunakan keluarga font yang sama dengan weight berbeda untuk hierarchy.

Display + Sans Serif

Display digunakan untuk headline, sedangkan sans serif menjaga teks informasi tetap mudah dibaca.

Satu keluarga font

Gunakan beberapa weight dari satu keluarga font untuk desain yang lebih konsisten.

Aturan sederhana untuk pemula

  1. Mulai dengan maksimal dua jenis keluarga font.
  2. Pastikan keduanya mempunyai perbedaan yang cukup jelas.
  3. Jangan memilih dua font yang terlihat hampir sama tetapi sebenarnya berbeda.
  4. Gunakan font dekoratif hanya jika sesuai dengan tema.
  5. Pastikan semua teks tetap mudah dibaca.
Hindari font overload: Jika satu poster menggunakan banyak font berbeda, desain dapat kehilangan identitas visual dan terlihat tidak teratur.

11. Warna Teks

Warna teks harus dipilih berdasarkan background, tujuan desain, dan tingkat keterbacaan. Warna yang bagus belum tentu cocok jika kontrasnya terlalu rendah.

Kontras

Kontras adalah perbedaan visual antara teks dan background. Teks harus mempunyai perbedaan yang cukup agar mudah dibaca.

Background terang

Gunakan teks yang cukup gelap atau warna yang memiliki kontras tinggi.

Background gelap

Gunakan teks yang cukup terang atau warna yang jelas terlihat.

Warna untuk hierarchy

Tidak semua teks harus memiliki warna berbeda. Gunakan satu warna utama dan satu warna aksen jika diperlukan. Terlalu banyak warna dapat mengurangi fokus.

Tips: Setelah memilih warna teks, lihat desain pada jarak normal. Jika kamu harus mendekat untuk membaca, kemungkinan kontras atau ukuran teks perlu diperbaiki.

12. Efek Teks Sederhana

Photoshop menyediakan beberapa efek yang dapat digunakan untuk memperkuat tampilan teks. Efek sebaiknya digunakan sebagai pendukung, bukan sebagai tujuan utama.

Efek yang dapat dipelajari

Drop Shadow

Memberikan bayangan pada teks sehingga dapat terlihat lebih terpisah dari background.

Stroke

Memberikan garis di sekitar huruf. Dapat membantu teks lebih terlihat pada background tertentu.

Outer Glow

Memberikan cahaya di sekitar teks untuk efek visual tertentu.

Gradient Overlay

Memberikan variasi warna pada teks menggunakan gradasi.

Contoh langkah membuat Drop Shadow

1 Pilih Text Layer.
2 Buka pengaturan Layer Style.
3 Pilih Drop Shadow.
4 Atur opacity, distance, spread, dan size sesuai kebutuhan.
5 Periksa hasil pada background.
6 Jangan membuat bayangan terlalu kuat jika desain membutuhkan kesan sederhana.
Ingat: Efek yang terlalu banyak dapat membuat teks sulit dibaca. Typography yang kuat biasanya tetap terlihat jelas meskipun efeknya sederhana.

13. Workflow Membuat Desain Typography

Berikut alur yang dapat digunakan ketika membuat desain berbasis typography:

  1. Tentukan pesan. Apa yang ingin disampaikan?
  2. Tentukan target. Siapa yang akan melihat desain?
  3. Tentukan tema. Modern, formal, kreatif, retro, elegan, edukatif, dan sebagainya.
  4. Pilih font utama. Mulai dari satu font yang paling sesuai.
  5. Tentukan hierarchy. Tentukan judul, subjudul, isi, dan informasi tambahan.
  6. Atur font size. Pastikan perbedaan tingkat informasi terlihat.
  7. Atur tracking dan leading. Perbaiki jarak huruf dan antarbaris.
  8. Atur alignment. Pilih arah teks yang sesuai dengan komposisi.
  9. Pilih warna. Pastikan kontras dengan background.
  10. Tambahkan efek jika diperlukan. Jangan berlebihan.
  11. Evaluasi. Lihat desain dari jauh dan pastikan pesan utama mudah ditemukan.
Urutan mudah:
PESAN → TEMA → FONT → HIERARCHY → SIZE → SPACING → ALIGNMENT → WARNA → EFEK → CEK KETERBACAAN.

14. Proyek: Membuat Desain Tipografi dengan Tema Tertentu

Judul Proyek

“Typography Poster — Pesan dalam Huruf”

Buat sebuah desain poster yang menggunakan typography sebagai elemen visual utama. Pilih satu tema dan komunikasikan pesan melalui ukuran, font, jarak, warna, dan susunan teks.

Pilihan tema

Pendidikan

Contoh: “Belajar Hari Ini, Berkarya Esok Hari”.

Motivasi

Contoh: “Berani Mulai, Berani Berkembang”.

Kreativitas

Contoh: “Ide Tidak Pernah Berhenti”.

Lingkungan

Contoh: “Jaga Bumi, Jaga Masa Depan”.

Teknologi

Contoh: “Masa Depan Dimulai dari Ide”.

Sekolah

Buat poster promosi atau kampanye positif bertema sekolah.

Ketentuan desain

  • Typography harus menjadi elemen utama.
  • Gunakan minimal dua tingkat hierarchy.
  • Gunakan minimal satu pengaturan tracking atau leading secara sadar.
  • Gunakan alignment yang jelas.
  • Gunakan maksimal dua keluarga font utama untuk menjaga konsistensi.
  • Gunakan warna teks yang mempunyai kontras dengan background.
  • Efek teks boleh digunakan, tetapi tidak wajib.

Langkah proyek secara lengkap

1 Tentukan tema. Pilih satu tema yang ingin disampaikan.
2 Buat dokumen. Gunakan ukuran canvas sesuai kebutuhan proyek, misalnya ukuran poster digital.
3 Tulis pesan utama. Buat satu kalimat pendek yang menjadi headline.
4 Buat headline menggunakan Point Text. Atur font, ukuran, weight, warna, dan posisinya.
5 Buat informasi pendukung. Jika membutuhkan paragraf atau deskripsi, gunakan Paragraph Text.
6 Bangun hierarchy. Pastikan headline lebih dominan daripada informasi tambahan.
7 Atur tracking. Gunakan tracking untuk mengatur jarak antarhuruf pada bagian tertentu.
8 Atur leading. Jika ada teks beberapa baris, atur jarak antarbaris agar nyaman dibaca.
9 Atur alignment. Gunakan left, center, right, atau justify sesuai komposisi.
10 Periksa warna. Pastikan teks mempunyai kontras yang cukup terhadap background.
11 Tambahkan efek sederhana jika diperlukan. Misalnya Drop Shadow atau Stroke yang ringan.
12 Evaluasi. Tanyakan: apakah pesan utama langsung terlihat? Apakah teks mudah dibaca? Apakah desain terlalu ramai?
13 Simpan file. Simpan file PSD agar seluruh Text Layer tetap dapat diedit.

Checklist proyek

☐ Tema desain jelas.
☐ Typography menjadi elemen utama.
☐ Headline mudah ditemukan.
☐ Hierarchy terlihat jelas.
☐ Font sesuai dengan tema.
☐ Tracking digunakan dengan tepat.
☐ Leading nyaman dibaca.
☐ Alignment konsisten.
☐ Warna teks memiliki kontras.
☐ Efek tidak berlebihan.
☐ Text Layer masih editable.
☐ File PSD tersedia.

Dokumentasi yang dikumpulkan

  1. File PSD.
  2. JPG/PNG hasil akhir.
  3. Screenshot panel Layers yang menunjukkan Text Layer.
  4. Screenshot pengaturan teks jika diminta.
  5. Penjelasan singkat mengenai alasan memilih font, warna, hierarchy, dan alignment.

15. Kesalahan Umum dalam Typography

1. Terlalu banyak font

Menggunakan terlalu banyak font membuat desain kehilangan konsistensi. Mulailah dengan satu atau dua keluarga font.

2. Semua teks dibuat sama besar

Jika semua teks memiliki ukuran yang sama, pembaca akan kesulitan mengetahui informasi utama. Gunakan hierarchy.

3. Kontras warna terlalu rendah

Teks yang warnanya terlalu mirip dengan background sulit dibaca. Tingkatkan kontras.

4. Tracking terlalu lebar

Jarak huruf yang terlalu lebar dapat membuat kata terlihat terpecah. Gunakan tracking sesuai kebutuhan visual.

5. Leading terlalu rapat

Baris teks dapat terlihat menumpuk. Atur leading agar setiap baris mempunyai ruang yang cukup.

6. Efek teks terlalu banyak

Drop Shadow, Stroke, Glow, Gradient, dan efek lainnya tidak harus digunakan semuanya. Pilih efek yang benar-benar mendukung desain.

7. Font tidak sesuai tema

Font yang cocok untuk poster teknologi belum tentu cocok untuk undangan formal. Selalu hubungkan pilihan font dengan pesan dan karakter desain.

8. Tidak memperhatikan keterbacaan

Desain harus tetap bisa dibaca. Keindahan font tidak boleh mengalahkan fungsi komunikasi.

16. Latihan Soal — 5 Pertanyaan

Jawablah pertanyaan berikut untuk menguji pemahamanmu.

Soal 1 — Apa yang dimaksud dengan typography?

Jawaban: Typography adalah seni dan teknik mengatur huruf atau teks agar informasi dapat disampaikan dengan jelas, nyaman dibaca, dan mempunyai tampilan visual yang sesuai dengan tujuan desain.

Soal 2 — Apa perbedaan Point Text dan Paragraph Text?

Jawaban: Point Text dibuat dengan satu klik dan cocok untuk teks pendek seperti judul. Paragraph Text dibuat dengan membuat area teks dan lebih cocok untuk paragraf atau teks yang lebih panjang.

Soal 3 — Apa yang dimaksud dengan tracking dan leading?

Jawaban: Tracking adalah pengaturan jarak antarhuruf secara keseluruhan pada teks, sedangkan leading adalah pengaturan jarak vertikal antarbaris.

Soal 4 — Apa fungsi hierarchy dalam typography?

Jawaban: Hierarchy membantu menunjukkan tingkat kepentingan informasi sehingga pembaca mengetahui bagian mana yang harus diperhatikan terlebih dahulu.

Soal 5 — Mengapa kombinasi font harus dilakukan dengan hati-hati?

Jawaban: Karena terlalu banyak atau kombinasi font yang tidak harmonis dapat membuat desain terlihat tidak teratur dan mengurangi keterbacaan.

17. 5 Tugas Praktik

Tugas 1 — Eksperimen Type Tool

Buat dokumen baru dan buat minimal lima Text Layer menggunakan Type Tool. Gunakan variasi font, ukuran, warna, dan alignment.

Tujuan: mengenal dasar penggunaan Type Tool dan Text Layer.

Output: PSD + JPG/PNG.

Tugas 2 — Point Text vs Paragraph Text

Buat satu desain sederhana yang berisi satu judul menggunakan Point Text dan satu paragraf menggunakan Paragraph Text. Atur font, ukuran, leading, dan alignment.

Tujuan: memahami perbedaan dua jenis teks.

Output: PSD + screenshot hasil.

Tugas 3 — Eksperimen Tracking dan Leading

Buat tiga contoh judul dengan tracking berbeda dan tiga contoh paragraf dengan leading berbeda. Bandingkan mana yang paling nyaman dibaca dan jelaskan alasannya.

Tujuan: memahami pengaruh spacing terhadap typography.

Output: satu file PSD berisi semua percobaan + penjelasan singkat.

Tugas 4 — Kombinasi Font

Buat satu desain menggunakan dua keluarga font. Gunakan satu untuk headline dan satu untuk informasi pendukung. Pastikan keduanya mempunyai hubungan visual yang baik.

Tujuan: melatih pemilihan dan kombinasi font.

Output: JPG/PNG + PSD.

Tugas 5 — Proyek Typography

Buat poster tipografi dengan satu tema pilihan. Typography harus menjadi elemen visual utama. Gunakan hierarchy, font, font size, tracking, leading, alignment, warna, dan jika diperlukan satu efek teks sederhana.

Tujuan: menerapkan seluruh materi typography ke dalam satu karya.

Output: 1 PSD, 1 JPG/PNG, dan 2–3 screenshot proses.

  • Type Tool digunakan untuk membuat dan mengedit teks.
  • Point Text cocok untuk judul atau teks pendek.
  • Paragraph Text cocok untuk teks yang lebih panjang.
  • Font harus dipilih sesuai tema dan karakter desain.
  • Font Size membantu membangun hierarchy.
  • Tracking mengatur jarak antarhuruf secara keseluruhan.
  • Leading mengatur jarak vertikal antarbaris.
  • Alignment membantu membuat teks tersusun rapi.
  • Hierarchy membantu pembaca mengetahui informasi yang paling penting.
  • Kombinasi font harus sederhana dan harmonis.
  • Warna teks harus mempunyai kontras yang cukup dengan background.
  • Efek teks dapat digunakan sebagai pendukung, bukan sebagai tujuan utama.
  • Text Layer sebaiknya dipertahankan agar teks masih mudah diedit.
