Bagian 4

↔️ Memahami Baris dan Kolom

Dalam tabel data, baris dan kolom memiliki fungsi yang berbeda.

IstilahPengertianContoh
Baris (row)Satu record atau satu objek data.Baris Andi berisi semua data milik Andi.
Kolom (column)Satu jenis informasi atau atribut.Kolom Matematika berisi nilai Matematika semua siswa.
Dataset
→

→
Kolom = jenis informasi
Cara mudah mengingat: Baris biasanya dibaca mendatar, sedangkan kolom biasanya dibaca tegak dari atas ke bawah.
Bagian 5

📊 Mengenal DataFrame

DataFrame adalah struktur data berbentuk tabel yang disediakan oleh Pandas. DataFrame memiliki baris dan kolom sehingga sangat cocok untuk pengolahan dataset.

BarisMewakili record atau objek data.
KolomMewakili atribut atau jenis data.
IndexMemberi penanda posisi baris.
Nama kolomMembantu kita memilih data yang ingin diolah.

Bagian 6

🐼 Mengenal Pandas

Pandas adalah library Python yang banyak digunakan untuk bekerja dengan data berbentuk tabel.

Mengapa menggunakan Pandas?

📥 Membaca dataDapat digunakan untuk membaca file seperti CSV.
📋 Mengatur dataData dapat disimpan dalam DataFrame.
🔎 Mencari dataKita dapat memilih kolom atau menyaring baris.
📈 Menganalisis dataRata-rata, jumlah, nilai maksimum, dan minimum dapat dihitung dengan mudah.
Analogi sederhana: Jika dataset adalah sebuah tabel nilai di spreadsheet, maka Pandas adalah alat Python yang membantu kita membaca dan mengolah tabel tersebut secara terprogram.

Bagian 8

🧱 Membuat DataFrame

Kita dapat membuat DataFrame langsung dari dictionary Python.

import pandas as pd

data = {
    "Nama": ["Andi", "Budi", "Citra", "Dina"],
    "Matematika": [80, 70, 90, 85],
    "Bahasa": [75, 80, 95, 80],
    "Informatika": [90, 75, 92, 88]
}

df = pd.DataFrame(data)

print(df)

Memahami kode

  1. import pandas as pd memanggil library Pandas.
  2. data menyimpan data dalam dictionary.
  3. Setiap key seperti Nama dan Matematika menjadi nama kolom.
  4. List di dalam dictionary menjadi isi setiap kolom.
  5. pd.DataFrame(data) mengubah data menjadi tabel.
  6. print(df) menampilkan DataFrame.

Bagian 10

🧮 Mengolah Data dengan Pandas

Rata-rata nilai Matematika

rata_matematika = df["Matematika"].mean()
print("Rata-rata Matematika:", rata_matematika)

Nilai tertinggi

tertinggi = df["Matematika"].max()
print("Nilai tertinggi:", tertinggi)

Nilai terendah

terendah = df["Matematika"].min()
print("Nilai terendah:", terendah)

Rata-rata semua mata pelajaran

kolom_nilai = ["Matematika", "Bahasa", "Informatika"]

df["Rata-rata"] = df[kolom_nilai].mean(axis=1)

print(df)

axis=1 berarti perhitungan dilakukan mendatar untuk setiap baris siswa.

Konsep penting: mean() untuk rata-rata, max() untuk nilai terbesar, dan min() untuk nilai terkecil.

Target analisis

Langkah 1 — Membuat DataFrame

import pandas as pd

data = {
    "Nama": ["Andi", "Budi", "Citra", "Dina"],
    "Matematika": [80, 70, 90, 85],
    "Bahasa": [75, 80, 95, 80],
    "Informatika": [90, 75, 92, 88]
}

df = pd.DataFrame(data)

df

print("Rata-rata Matematika:", df["Matematika"].mean())

kolom_nilai = ["Matematika", "Bahasa", "Informatika"]

df["Rata-rata"] = df[kolom_nilai].mean(axis=1)

index_tertinggi = df["Rata-rata"].idxmax()

print("Siswa dengan rata-rata tertinggi:")
print(df.loc[index_tertinggi])

Bagian 13

🚀 Proyek Mini — Analisis Data Nilai Siswa

Buat notebook Google Colab yang dapat membuat atau membaca dataset nilai siswa, kemudian melakukan analisis sederhana.

Ketentuan minimal

  1. Dataset memiliki minimal 5 siswa.
  2. Memiliki kolom Nama.
  3. Memiliki minimal 3 kolom mata pelajaran.
  4. Data disimpan dalam DataFrame.
  5. Menampilkan rata-rata setiap mata pelajaran.
  6. Menambahkan kolom rata-rata setiap siswa.
  7. Menampilkan siswa dengan rata-rata tertinggi.
  8. Menampilkan siswa dengan nilai tertinggi dan terendah pada salah satu mata pelajaran.

Kode proyek contoh

import pandas as pd

# 1. Membuat dataset
data = {
    "Nama": ["Andi", "Budi", "Citra", "Dina", "Eko"],
    "Matematika": [80, 70, 90, 85, 78],
    "Bahasa": [75, 80, 95, 80, 82],
    "Informatika": [90, 75, 92, 88, 85]
}

# 2. Membuat DataFrame
df = pd.DataFrame(data)

# 3. Menampilkan dataset
print("=== DATASET NILAI SISWA ===")
print(df)

# 4. Menentukan kolom nilai
kolom_nilai = ["Matematika", "Bahasa", "Informatika"]

# 5. Menghitung rata-rata setiap siswa
df["Rata-rata"] = df[kolom_nilai].mean(axis=1)

# 6. Rata-rata setiap mata pelajaran
print("\n=== RATA-RATA MATA PELAJARAN ===")
for kolom in kolom_nilai:
    print(kolom, ":", df[kolom].mean())

# 7. Siswa dengan rata-rata tertinggi
index_tertinggi = df["Rata-rata"].idxmax()
siswa_tertinggi = df.loc[index_tertinggi]

print("\n=== SISWA DENGAN RATA-RATA TERTINGGI ===")
print(siswa_tertinggi)

# 8. Menampilkan hasil akhir
print("\n=== DATA AKHIR ===")
print(df)

Pengembangan proyek

Level 1Tambahkan minimal 10 siswa.
Level 2Tambahkan kolom predikat A–E.
Level 3Hitung jumlah siswa yang rata-ratanya minimal 75.
Level 4Buat grafik nilai menggunakan Matplotlib.
