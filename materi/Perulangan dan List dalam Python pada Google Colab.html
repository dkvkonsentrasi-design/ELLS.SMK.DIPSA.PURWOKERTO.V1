Bagian 3

📦 Mengenal List dalam Python

List adalah struktur data untuk menyimpan beberapa nilai dalam satu variabel. List ditulis dengan tanda kurung siku [ ].

nama_siswa = ["Andi", "Budi", "Citra", "Dina"]
print(nama_siswa)

Dengan list, kita tidak perlu membuat variabel nama1, nama2, dan seterusnya.

List berisi angka

nilai = [80, 75, 90, 85, 70]
print(nilai)
List kosongnilai = []
Dapat diisi kemudian.
List angkanilai = [70, 80, 90]
Cocok untuk pengolahan nilai.
List teksbuah = ["Apel", "Mangga"]
Cocok untuk nama atau kategori.
List campuranPython juga dapat menyimpan tipe data berbeda, walaupun untuk data nilai sebaiknya konsisten.
Bagian 4

🔎 Mengakses Data dalam List

Posisi data disebut index. Python mulai menghitung dari 0.

Index0123
Data80759085
nilai = [80, 75, 90, 85]
print(nilai[0])
print(nilai[1])
print(nilai[2])

nilai[0] berarti data pertama. nilai[-1] berarti data terakhir.

Kesalahan umum: Jika list memiliki empat data, index yang tersedia adalah 0, 1, 2, dan 3. Index 4 tidak tersedia.
Bagian 5

✏️ Mengubah dan Menambah Data

Mengubah data

nilai = [80, 75, 90]
nilai[1] = 78
print(nilai)

Menambah satu data dengan append()

nilai = [80, 75, 90]
nilai.append(85)
print(nilai)

append() menambahkan satu data ke bagian akhir list.

Menambah beberapa data

nilai = [80, 75, 90]
nilai.extend([85, 88])
print(nilai)
Ingat: append() untuk satu item; extend() untuk menambahkan beberapa item dari iterable seperti list lain.
Bagian 6

🔁 Perulangan for

Perulangan menjalankan instruksi berkali-kali. for sangat cocok untuk membaca setiap data dalam list.

nama_siswa = ["Andi", "Budi", "Citra", "Dina"]

for nama in nama_siswa:
    print(nama)

Cara membacanya: untuk setiap nama di dalam nama_siswa, tampilkan nama tersebut.

Ambil data
→
Jalankan perintah
→
Data berikutnya
→
Selesai

Contoh menghitung total

nilai = [80, 75, 90, 85]
total = 0

for n in nilai:
    total = total + n

print("Total:", total)

Variabel total dimulai dari 0, lalu setiap nilai ditambahkan satu per satu.

Bagian 7

🔄 Perulangan while

while menjalankan kode selama kondisi masih benar.

angka = 1

while angka <= 5:
    print(angka)
    angka = angka + 1

Nilai angka berubah setiap putaran sehingga akhirnya kondisi menjadi salah dan perulangan berhenti.

Hati-hati infinite loop: Jika variabel pengendali tidak berubah menuju kondisi berhenti, perulangan dapat berjalan terus.
forwhile
Cocok untuk memproses item dalam list atau sejumlah langkah tertentu.Cocok ketika jumlah putaran bergantung pada kondisi.
Contoh: memproses 10 nilai.Contoh: meminta input sampai kondisi terpenuhi.
Bagian 8

🔢 Menggunakan range()

range() menghasilkan urutan angka yang sering digunakan bersama for.

for i in range(5):
    print(i)

Hasilnya 0, 1, 2, 3, 4. Batas akhir tidak ikut dihitung.

for i in range(1, 6):
    print(i)

Hasilnya 1 sampai 5.

Meminta 10 nilai

nilai = []

for i in range(10):
    angka = float(input(f"Masukkan nilai ke-{i+1}: "))
    nilai.append(angka)

print("Data nilai:", nilai)
Gabungan konsep: range(10) membuat 10 putaran, input() mengambil data, dan append() menyimpan data ke list.
Bagian 9

🧩 Menggabungkan List dan Perulangan

List menyimpan banyak data, sedangkan perulangan memproses data tersebut satu per satu.

nilai = [80, 75, 90, 85, 70]

for i, n in enumerate(nilai, start=1):
    print(f"Nilai ke-{i}: {n}")

enumerate() memberi nomor urut sekaligus nilai.

Menghitung rata-rata secara bertahap

nilai = [80, 75, 90, 85, 70]
total = 0

for n in nilai:
    total += n

rata_rata = total / len(nilai)
print("Rata-rata:", rata_rata)

Rumusnya adalah rata-rata = total nilai ÷ jumlah data.

Bagian 10

📊 Menghitung Nilai

FungsiKegunaan
sum(list)Menjumlahkan semua angka.
len(list)Menghitung jumlah data.
max(list)Mencari nilai terbesar.
min(list)Mencari nilai terkecil.
nilai = [80, 75, 90, 85, 70]

print("Jumlah data    :", len(nilai))
print("Total nilai    :", sum(nilai))
print("Rata-rata      :", sum(nilai) / len(nilai))
print("Nilai tertinggi:", max(nilai))
print("Nilai terendah :", min(nilai))
Belajar konsep: Cobalah lebih dulu menghitung total menggunakan for. Setelah memahami logikanya, gunakan sum(), max(), dan min() untuk membuat kode lebih ringkas.

Mencari nilai tertinggi dengan perulangan

nilai = [80, 75, 90, 85, 70]
tertinggi = nilai[0]

for n in nilai:
    if n > tertinggi:
        tertinggi = n

print("Nilai tertinggi:", tertinggi)
